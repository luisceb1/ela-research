# Protocolo de evidencia y calidad

Cada análisis científico debe registrar:
1. Pregunta precisa y predicción que podría refutarla.
2. Dataset, accession GSE/GSM, archivos, URL, fecha y hashes/versiones.
3. Grupos, controles, origen de muestras y número de réplicas biológicas.
4. Métodos, parámetros, dependencias y semilla aleatoria si aplica.
5. Tablas exportables y código ejecutado; nunca gráficos simulados.
6. Análisis de sensibilidad, limitaciones, sesgos y explicaciones alternativas.
7. Distinción entre observación de splicing, rescate molecular, función neuronal y beneficio clínico.
8. Etiqueta de evidencia: exploratoria, reproducida externamente, contrastada funcionalmente o insuficiente.
9. Próxima prueba discriminante y criterio para abandonar la hipótesis.

No recomendar tratamientos, intervenciones ni cambios de medicación a partir de análisis exploratorios.
