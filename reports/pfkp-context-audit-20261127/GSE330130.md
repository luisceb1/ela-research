# GSE330130 — target-blind donor/cell-type admission audit

**Date:** 27 November 2026. Internal working record. No public release.
**Decision:** Do not execute the primary PFKP cell-specific expression contrast in this matrix. Captured motor-neuron representation is severely unbalanced across donors. This is a design/coverage result, not a PFKP expression result.

## Schema and independent units

H5AD contains X in CSR format, with shape 121,881 × 36,601 and 211,095,485 stored entries (integer int64 data, int32 indices). No target gene values or target gene positions were extracted. No X expression values were read: this audit used only encoded observation fields and reported per-nucleus n_counts. X library-size reconciliation not performed.

Relevant observation fields: Level 1 (ALS/Control), Cell_Type, Subject ID, library_id, Tissue Type, n_counts. Additional demographic fields exist but were not read. All grouping keys have zero missing codes. One diagnosis and one library per subject; one subject per library. 20 subjects/libraries (11 ALS, 9 controls), all lumbar spinal cord. Nine observed broad cell labels in the file; the publication describes ten classes, so the exact taxonomy difference is unresolved.

### Target-blind eligibility sensitivity

Count of subjects passing a symmetric minimum captured-nuclei requirement in **both** MN and other-neuron classes, plus at least 10,000 summed author n_counts in each class. The size grid is a descriptive design diagnostic, not a series of target tests, and no cutoff is selected for an expression analysis.

| Minimum nuclei per class | ALS | Control |
|---:|---:|---:|
| 5 | 5 | 3 |
| 10 | 4 | 1 |
| 20 | 2 | 1 |
| 30 | 1 | 1 |
| 50 | 0 | 1 |
| 100 | 0 | 1 |

No defensible independent-donor specificity contrast is admitted under these conditions. Even an inclusive threshold of 5 nuclei leaves only 5 vs 3; at 10 the controls collapse to one. Relaxing further or treating cell nuclei as independent would change the estimand and cannot turn this design into independent validation. No exclusions, normalization or PFKP model were run.

## Reproducibility

Below is the target-blind aggregate audit logic (equivalent to the executed two read-only summaries). It does not output subject codes, individual measurements or expression data.

```python
import h5py
import numpy as np
import pandas as pd

path = "GSE330130_LSC_SNRNASEQ_COUNTS.h5ad"
with h5py.File(path, "r") as f:
    o = f["obs"]
    def codes(k): return o[k]["codes"][:]
    def labels(k): return o[k]["categories"].asstr()[:]
    for k in ("Subject ID", "Level 1", "Cell_Type", "library_id", "Tissue Type"):
        assert (codes(k) >= 0).all()
    df = pd.DataFrame({
        "subject": codes("Subject ID"),
        "diagnosis": labels("Level 1")[codes("Level 1")],
        "cell": labels("Cell_Type")[codes("Cell_Type")],
        "library": codes("library_id"),
        "n_counts": o["n_counts"][:],
    })
    assert df.groupby("subject").diagnosis.nunique().max() == 1
    assert df.groupby("subject").library.nunique().max() == 1
    assert df.groupby("library").subject.nunique().max() == 1
    print(pd.crosstab(df.cell, df.diagnosis))
    group = df.groupby(["diagnosis", "subject"]).size().to_frame("total")
    mn = df.cell.eq("Motor Neurons")
    other = df.cell.isin(["Excitatory  Neuron", "Inhibitory Neuron"])
    for name, mask in [("MN", mn), ("Other", other)]:
        group[name] = df[mask].groupby(["diagnosis", "subject"]).size()
        group[name+"_counts"] = df[mask].groupby(["diagnosis", "subject"]).n_counts.sum()
    group = group.fillna(0)
    for dx, a in group.groupby(level=0):
        print(dx, "subjects", len(a), "totals", a.sum().to_dict())
        print("paired coverage", int(((a.MN >= 1) & (a.Other >= 1)).sum()))
        print("MN range/median", a.MN.min(), a.MN.median(), a.MN.max())
        print("top MN share", a.MN.max()/a.MN.sum())
        for k in (5, 10, 20, 30, 50, 100):
            passed = ((a[["MN", "Other"]] >= k).all(axis=1)
                      & (a[["MN_counts", "Other_counts"]] >= 10000).all(axis=1))
            print(k, int(passed.sum()))
```

## Decision and next discriminating input

- Close this specific GSE330130 lumbar primary expression route on recorded donor coverage grounds, **before target inspection**. Do not generalize the result to other modalities, regions, cohorts or genes.
- PFKP hypothesis remains unanswered; Guise protein finding, Manzo RNA increases and the five-study proteomic discrepancies remain intact.
- GSE287257 is still a conditional alternative, not a replication result. Require documented original cell-type annotation and sufficiently distributed motor-neuron capture in independent donors before any target analysis. Broad neuron labels are insufficient. A published 2026 vascular reanalysis of GSE287257 (PMC13660197) confirms availability of H5 count matrices but does not establish MN-specific coverage.
- No MTC substitution or raw archive download without a genuinely distinct prespecified question. No row-level export or public dissemination.

This is a source-design result, not independent biological validation, a novel pathogenic mechanism or evidence of clinical benefit.
